# Space Shooter

A simple Python game built with Pygame. This project includes a player sprite, stars, meteor, and laser visuals for a basic space shooter prototype.

## NOT COMPLETED RIGHT NOW!

## Project structure

- `code/main.py` — main game script
- `images/` — game image assets
- `audio/` — audio assets (if added later)

## Run locally

1. Install Pygame:
   ```bash
   pip install pygame
   ```
2. Run the game:
   ```bash
   python code/main.py
   ```

## Notes

- The game currently uses placeholder assets and a simple loop structure.
- Update `code/main.py` to add controls, enemies, and collision handling.
- Keep assets inside the `images` folder and use relative paths from `code/main.py`.
